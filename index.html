ABOUT

关于偏航

一款鼓励你偏离最短路径的城市步行探索应用。

偏
偏航 · Pianhang Version 1.0.0

我们在做什么

综合你的空闲时间、天气、出行方式与兴趣偏好，用大模型生成三条“非最短但值得”的城市路线，带你走进平时容易忽略的街角。

技术栈

HTML / CSS / JS Leaflet FastAPI OpenStreetMap OSRM Open-Meteo LLM

隐私说明

位置信息仅用于本次路线规划；账号体系只保存用户名、昵称、城市与一句话简介，不收集手机号等敏感信息。
